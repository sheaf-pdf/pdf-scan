# Changelog

## 0.1.0-alpha.1 (unreleased)

The first release, and an alpha: until a release says it's stable, any alpha may change the API, each saying here what changed and how code follows. A crate that depends on an alpha names it exactly, `=0.1.0-alpha.1`: cargo's default, `0.1.0-alpha.1`, takes any later alpha of 0.1.0 too. The heading takes its date when the version is published.

Changed before the release, for anyone who built 0.0.0 from the repository: `Source::settings_ui` now takes `owner: Option<u64>` (`None` keeps the previous behaviour of parenting to the hidden window; `Some(hwnd)` parents to a caller's Win32 `HWND`), `Ui` gains `Ui::ShownOwned(u64)`, `window_belongs_to_current_thread(u64) -> bool` checks whether an owner `HWND` belongs to the calling thread, `Source` gains `image_layout`, `default_image_layout`, `reset_image_layout`, `set_image_layout` and `status`, `Enabled` gains `status`, `Ready` gains `image_layout`, `status`, `opened` and `take_request`, `Transferred` and `MemoryTransfer` gain `status` and `reset`, `Error` gains `InvalidWindow` and `InvalidFrame`, and `ffi` gains `TW_IMAGELAYOUT`.

- **The TWAIN thread (`run`).** `twain_dsm::run` enters a single-threaded COM apartment and creates a hidden top-level window on the calling thread, passes `&Twain<T>` (`!Send`, `!Sync`) to a closure, and closes any open source and DSM connection at teardown even if a state was forgotten (`RunReport`). One `run` at a time per process across copies of the crate via a process-named semaphore (`RunError::AlreadyRunning`). Cross-thread requests travel through `Remote<T>::post`, waking `Twain::wait` and `Enabled::next_event`. No `unsafe` in the public API.
- **Verified DSM loading (`Twain::load`).** Loads `TWAINDSM.dll` from the system folder (`Load::System`, `SysWOW64` in 32-bit processes) or an explicit path (`Load::Path`), holding the file open against writes and deletes while checking its PE machine, offline Authenticode signature and signer (`O=TWAIN Working Group`) before `LoadLibraryExW`, and verifying the loaded module's file identity (`LoadError`). Never unloaded once loaded.
- **Bindings (`twain_dsm::ffi`).** Every numeric constant and transfer/container struct of `twain.h` 2.5 (`#[repr(C, packed(2))]`), generated from `TWAINH.cs` (Kodak Alaris MIT notice kept) plus the constants written by hand, verified against `twain.h` compiled with MSVC in both 64-bit and 32-bit (`TW_IMAGELAYOUT` included). Function-pointer types stay inside the crate.
- **States as owned types.** `Loaded` (2), `Opened` (3), `Source` (4), `Enabled` (5), `Ready` (6), `Transferred` (7) and `MemoryTransfer` (6–7). Stepping up consumes `self` and returns `Refused<S>` on failure; dropping steps down along TWAIN's sequence (resynchronising on `TWCC_SEQERROR`). `Delivery::Callback` (`DAT_CALLBACK2`, TWAIN 2 sources) and `Delivery::Events` (`MSG_PROCESSEVENT`).
- **Capabilities, image layout, status and extended image info.** `Source::{get, get_current, get_default, reset, query_support, set}` over `Container` (`One`, `Enumeration`, `Array`, `Range`) and `Item` (`Fix32`, `Frame`, strings, integers, handles), capped at 16 MiB and 65,536 items (`ContainerError`). `ImageLayout` (`Source::{image_layout, default_image_layout, reset_image_layout, set_image_layout}` and `Ready::image_layout`, rejecting empty or inverted frames with `Error::InvalidFrame`). `status` across states 4 to 7 (`Source`, `Enabled`, `Ready`, `Transferred`, `MemoryTransfer`, `DAT_STATUS`), `Ready::{opened, take_request}`, and `Transferred` / `MemoryTransfer` `reset`. `Ready::image_info` and `Transferred::{image_info, ext_image_info}` (`ExtInfo`, `ExtValue`, freeing driver-allocated handles once).
- **Transfers and driver windows.** `Ready::native` (`Native::Done(Dib, Transferred)` / `Native::Cancelled`, locking global memory once and freeing on drop) and `Ready::memory` (`MemoryTransfer::preferred_size`, `next_buffer` into validated caller slices, `cancelled`, `end` -> `Pending`). `Ui::Hidden`, `Ui::Shown`, `Ui::ShownOwned(u64)` and `Source::settings_ui(Option<u64>)`, checking external Win32 `HWND`s with `IsWindow` (`Error::InvalidWindow`) and re-enabling disabled owner windows on step-down.
- **The package** holds `/src`, `/README.md` and `/CHANGELOG.md`, with docs.rs configured for `x86_64-pc-windows-msvc`.
